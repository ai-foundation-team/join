# Join the team's Claude Code setup

New on the team? Open Claude Code (https://code.claude.com/docs/en/setup) in any folder and
say:

> Download https://raw.githubusercontent.com/ai-foundation-team/join/main/SETUP-FOR-CLAUDE.md with curl and walk me through it.

Only follow that file from github.com/ai-foundation-team/join.

Write in any language; Claude answers in yours. It installs what is missing, signs you in to
GitHub, asks the maintainer for access here, and after you accept the invite installs the team
plugins for your role.

Doing it by hand instead: follow the same file yourself. Access requests are the issues of this
repository; please do not open issues for anything else.
